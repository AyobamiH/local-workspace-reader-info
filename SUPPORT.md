# Local Workspace Reader — support

**Developer:** AyobamiH. **Plugin:** Local Workspace Reader (`personal-desktop-commander`).

For help, bug reports, compatibility questions or a request concerning this plugin's data practices, open a [support issue](https://github.com/AyobamiH/local-workspace-reader-info/issues/new) in this public information repository. Sign-in to GitHub is required to create an issue.

When reporting a problem, give the plugin version, desktop operating system, the tool name, the expected result, and the observed error **with private paths and sensitive content removed**. Please do not post API keys, login credentials, email addresses, private file contents, screenshots of confidential data, or access tokens in a public issue. If you cannot safely describe a problem publicly, use GitHub's profile contact options and wait for a private channel before sharing any details.

The plugin is a private draft while undergoing validation; local MCP features will become available only on supported desktop installations after the relevant OpenAI approval and review processes. This support channel does not provide remote access to user machines or account credentials.

Related: [Privacy policy](PRIVACY.md) and [Terms of service](TERMS.md).
