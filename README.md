# Remote Desktop File Explorer

**Independent developer:** AyobamiH. This public repository contains the **support, privacy and terms documents only** for the Remote Desktop File Explorer plugin. It does not contain the private implementation, user data, tokens or local device executables.

The plugin connects ChatGPT to explicitly enrolled workspaces through `https://reader.proofandstate.com/mcp`. Its owner runtime supports file browsing, bounded reads and searches, and explicitly approved Linux file edits, PDF generation, isolated terminal processes and durable jobs with recorded outcomes. Exact one-use approval is required for effects. Windows enrollment is currently read-only. Screen control and general outbound networking are not available.

The product's next review package is branded **Proof & State Desktop**, retaining the same package identity `remote-desktop-file-explorer`. Its live-demo entry point is [reader.proofandstate.com/demo](https://reader.proofandstate.com/demo). Availability and the deployed demo version must be checked at that page; this document does not establish deployment, ChatGPT acceptance or publication. The full reviewer implementation uses a separate synthetic Linux workspace and device credential, not personal owner devices.

This is an independent tool. It is not affiliated with OpenAI or the commercial Remote Desktop Commander service. Availability depends on the local agent, OAuth authorisation and plugin approval.
