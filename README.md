# Local Workspace Reader — developer information

This public-information site belongs to **AyobamiH**, developer of the *Local Workspace Reader* plugin (package name `personal-desktop-commander`). The implementation and integration tests are maintained separately in a private GitHub repository; this site contains **no plugin credentials, source archives or user data**.

Local Workspace Reader is an optional, read-only MCP tool for opening a deliberately authorised local project folder and reading bounded excerpts from ordinary text files. The developer is not affiliated with OpenAI or the original Desktop Commander project's maintainers.

- [Privacy policy](PRIVACY.md)
- [Terms of service](TERMS.md)
- [Support and issue reporting](SUPPORT.md)

The plugin is being prepared for review and is not currently a publicly available service. It requires supported desktop execution and, before any public availability, OpenAI approval for a local MCP plugin.
